PIEMONTE BROKERS — VERSÃO ADMINISTRATIVA SEM BUILD

POR QUE ESTA VERSÃO É MAIS SIMPLES
Esta versão não usa Eleventy, npm, package.json ou processo de build.
O Netlify publica os arquivos diretamente.
Assim eliminamos o erro que estava acontecendo na etapa Building.

PAINEL
Depois de ativar Netlify Identity + Git Gateway, acesse:
https://SEU-SITE.netlify.app/admin/

NO PAINEL VOCÊ CONSEGUE
- trocar foto principal da Home;
- editar título e subtítulo;
- editar texto Sobre;
- editar WhatsApp, e-mail e Instagram;
- adicionar, editar e remover imóveis;
- adicionar, editar e remover áreas;
- subir foto de capa;
- subir galeria de fotos;
- alterar status, preço, metragem e descrição.

PUBLICAÇÃO
O painel salva a alteração no GitHub.
Como o Netlify está conectado ao GitHub, ele publica automaticamente.
Como não há build, o deploy é muito mais simples.

COMO SUBSTITUIR O PROJETO ATUAL NO GITHUB DESKTOP
1. Abra a pasta local do repositório pelo GitHub Desktop > Show in Explorer.
2. Faça uma cópia de segurança da pasta atual se quiser.
3. Apague da pasta local os arquivos antigos do site.
4. Extraia este ZIP.
5. Copie TODO o conteúdo extraído para dentro da pasta local do repositório.
6. Volte ao GitHub Desktop.
7. Escreva no Summary: Versão sem build
8. Commit to main.
9. Push origin.
10. Volte ao Netlify > Deploys.
11. O deploy deve iniciar automaticamente.
